# QuakeVR-Monolith-Edition

An unofficial virtual reality adaptation of Quake Brutalist Jam III, built upon QuakeVR


QuakeVR: Monolith Edition is an unofficial fork of QuakeVR

The project aims to preserve the distinctive atmosphere, weaponry and monsters of Monolith/QBJ3 while adapting its gameplay to the interactive systems of QuakeVR.

Note: I am aware QVR's latest iteration was created with ai-assisted tools. Originally it was created as a hand-made project and with my project I aim create my own custom maps, modeles, textures, and edits to the QuakeC. Otherwise it will simply be using assets provided by Quake 1 and the Monolith devkit.
